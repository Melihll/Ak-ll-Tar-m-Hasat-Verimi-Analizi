# Akıllı Tarım: Hasat Verimi Analizi ve Tahmini 🌾📊

Bu proje, tarımsal verimliliği artırmak ve üreticilerin doğru kararlar almasını sağlamak amacıyla geliştirilmiş veri odaklı bir **Makine Öğrenmesi (Machine Learning)** projesidir. Toprak özellikleri, iklim koşulları ve geçmiş hasat verilerini analiz ederek gelecekteki hasat verimini tahmin etmeyi amaçlar.

## 🚀 Proje Hakkında

Geleneksel tarım yöntemlerini modern veri bilimi teknikleriyle birleştirerek, hangi şartlarda ne kadar ürün elde edilebileceğini öngörüyoruz. Bu sayede kaynakların (su, gübre, zaman) daha efektif kullanılması hedeflenmektedir.

### 🛠️ Kullanılan Teknolojiler ve Kütüphaneler

* **Programlama Dili:** Python 🐍
* **Veri Analizi & Manipülasyon:** Pandas, NumPy
* **Veri Görselleştirme:** Matplotlib, Seaborn
* **Makine Öğrenmesi:** Scikit-Learn (Regresyon/Sınıflandırma Modelleri)
* **Geliştirme Ortamı:** Jupyter Notebook / VS Code

## 📈 İş Akışı ve Özellik Mühendisliği (Feature Engineering)

1.  **Veri Temizleme (Data Cleaning):** Eksik veya hatalı verilerin (outliers) tespiti ve manipülasyonu.
2.  **Keşifçi Veri Analizi (EDA):** Korelasyon matrisleri ve grafiklerle veriler arasındaki ilişkilerin keşfedilmesi.
3.  **Özellik Seçimi:** Model performansını artırmak için en anlamlı bağımsız değişkenlerin belirlenmesi.
4.  **Model Eğitimi:** Çeşitli makine öğrenmesi algoritmalarının (örn: Random Forest, Gradient Boosting, Linear Regression vb.) eğitilmesi ve hiperparametre optimizasyonu.
5.  **Değerlendirme:** Modellerin $R^2$, RMSE, MAE gibi metriklerle karşılaştırılması.
